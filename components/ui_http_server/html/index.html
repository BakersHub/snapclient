Snapcast Gain Boost notes
How it works:
Gain 0.5: reduced max volume for small speakers that are getting overpowered.

Gain 1 (default): Audio plays at its original level.
Gain 2: The audio signal is multiplied by 2 (doubling the waveform amplitude).

Important notes:
Perceived loudness: Doubling amplitude does not double perceived loudness. Roughly +10 dB (~3.16× gain) sounds “twice as loud”.
Clipping risk: If the signal is already near maximum, multiplying by 2 can clip and distort.
System volume: This gain just multiplies the signal; extra DAC/amp gain can easily overdrive hardware.

✅ Rule of thumb: Increase gain gradually (e.g. 1.0 → 1.2 → 1.5) and listen for distortion rather than jumping straight to high values.
Horizontal column offset for the panel. Classic SH1106 1.28" modules typically use 2, while many 0.96" SSD1306 128x64 modules use 0.
